About 📖

This project is Workshop 05 of the FullStack course. It demonstrates how to build a RESTful API using:

  • Node.js & Express – web server and routing
  • MongoDB & Mongoose – database and schema validation
  • REST conventions – proper HTTP methods and status codes
  • dotenv – environment variable management

The API supports full CRUD operations for blog posts (Create, Read, Update, Delete).
